# 雪人打怪兽 (Snowman vs Monsters)

一款基于微信小游戏平台的横版射击游戏，玩家控制雪人战士，通过喷射雪球、推动雪团消灭火焰恶魔等怪物，完成 8 个关卡的挑战。

## 玩法介绍

### 操作方式

| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| 跳 | 跳跃上平台 |
| 射 | 喷射雪球攻击敌人 |

### 核心玩法

1. **喷射雪球**：横向平射，击中敌人
2. **包裹敌人**：连续命中 3 次（大型敌人 4 次），敌人会变成大雪球
3. **推动雪球**：靠近大雪球自动推动，雪球可撞死其他敌人（+100分）
4. **通关条件**：消灭当前关卡所有敌人

### 道具系统

通关后随机获得道具：

| 道具 | 图标 | 效果 | 解锁时间 |
|------|------|------|---------|
| 巨雪球 | ❄ | 雪球体积变大 | 第3关后 |
| 速射 | ⚡ | 射击间隔变短 | 第4关后 |
| 疾风 | ✦ | 移动速度提升 | 第5关后 |

### 敌人类型

- **普通敌人**：红色火焰恶魔，基础属性
- **快速敌人**：移动速度更快
- **大型敌人**：体积更大，需要 4 次命中

## 开发说明

### 新增关卡

在 `src/systems/Level.js` 中的 `LEVELS` 数组添加新关卡：

```javascript
{
  name: '第N关',
  platforms: [
    { x: 0, y: 600, width: 750, height: 20 },  // 地面
    { x: 100, y: 450, width: 200, height: 15 } // 浮空平台
    // ...
  ],
  enemyTypes: ['basic', 'fast', 'big'],
  spawnPoints: [
    { x: 200, y: 400 }
    // ...
  ],
  playerStart: { x: 60, y: 540 }
}
```

### 自定义敌人

在 `Level.js` 的 `loadLevel` 方法中可以修改敌人属性：

```javascript
if (type === 'fast') {
  enemy.walkSpeed = 80  // 快速敌人
} else if (type === 'big') {
  enemy.width = 50      // 大型敌人
  enemy.height = 65
  enemy.maxCoverage = 4 // 需要更多命中
}
```

## 常见问题

### Q: 点击按钮没反应？
A: 确保触摸坐标正确获取（已修复 clientX/clientY 兼容性问题）。

### Q: 游戏白屏？
A: 检查基础库版本是否满足要求，查看控制台错误信息。

### Q: 平台跳不上去？
A: 调整 Player.js 中的 `jumpForce` 参数（默认 600），值越大跳得越高。
