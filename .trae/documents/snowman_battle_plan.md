# 雪人兄弟 - 微信小程序游戏设计方案 (v2.0)

## 一、项目概述

### 游戏主题
**雪人兄弟 (Snow Bros)** —— 经典横版动作闯关游戏复刻。玩家操控雪人角色，在冰雪平台上喷射雪球攻击敌人，将敌人包裹成大雪球推动消灭其他敌人，完成关卡挑战。

### 核心特色
- 🏃 **平台跳跃**：左右移动 + 跳跃的横版动作玩法
- ❄️ **雪球包裹**：喷射雪球逐渐包裹敌人，3-4 次命中将其变成大雪球
- 🟤 **推球消灭**：推动大雪球可以撞击消灭其他敌人
- 🗺️ **关卡系统**：多关卡递进，难度逐步提升
- 📱 **虚拟按键**：触屏虚拟摇杆 + 跳跃 + 射击按钮

## 三、游戏玩法设计

### 3.1 核心操作
```
┌───────────────────────────────────────┐
│                                       │
│         ☃️ 玩家雪人                    │
│        ╱ 喷射区 ╲                     │
│       ╱   (向上喷射)  ╲               │
│                                       │
│   ┌─────────────────────────────┐    │
│   │  冰 雪 平 台  (多层)         │    │
│   └─────────────────────────────┘    │
│                                       │
│  ╔═══╗              ╔═══╗           │
│  ║←→║   (左摇杆)     ║跳║  ║射║       │
│  ╚═══╝              ╚═══╝  ╚═══╝       │
└───────────────────────────────────────┘
```

### 3.2 操作方式
| 按键 | 功能 | 说明 |
|------|------|------|
| 左/右摇杆 | 移动 | 控制雪人左右走动 |
| 跳跃按钮 | 跳跃 | 可以跳上平台 |
| 射击按钮 | 喷射雪球 | 向上或向前喷射小雪球 |

### 3.3 战斗机制
```
敌人被击中过程:
  原始敌人 → 第1击(1层雪) → 第2击(2层雪) → 第3击(3层雪, 可推动!)
     🟤        ⬜▫️          ⬜▫️▪️         ⬜⬜⬜ (变成大雪球)

推动大雪球:
  玩家靠近大雪球 → 推动雪球 → 雪球滚动 → 撞击敌人 → 消灭敌人
```

### 3.4 关卡流程
```
第1关: 3个敌人 (简单)
  ↓ 清除所有敌人
第2关: 5个敌人 (中等)
  ↓ 清除所有敌人
第3关: 7个敌人 + 移动平台 (困难)
  ↓ 清除所有敌人
胜利画面
```

### 3.5 碰撞系统
- **雪球 vs 敌人**：命中后增加雪层，3层后变成可推动大雪球
- **玩家 vs 大雪球**：接触时推动，雪球滚动消灭其他敌人
- **玩家 vs 敌人**：接触扣血
- **玩家 vs 平台**：平台碰撞，可站立/跳跃
- **大雪球 vs 敌人**：消灭敌人

## 四、核心模块设计

### 4.1 玩家 (Player)
```
属性:
  - x, y (位置)
  - vx, vy (速度)
  - width, height (尺寸)
  - facing (朝向: left/right)
  - onGround (是否在地面)
  - hp (血量)
  - snowLayer (自身雪层, 0-3)
  - invincible (无敌时间)
```

### 4.2 敌人 (Enemy)
```
属性:
  - x, y, vx, vy
  - snowCoverage (0-3, 雪层覆盖)
  - state (walking/covered/pushed/dead)
  - patrolRange (巡逻范围)
  - platformId (所在平台ID)
```

### 4.3 关卡 (Level)
```
结构:
  - platforms: 平台数组
  - enemies: 敌人数组
  - spawnPoints: 敌人生成点
  - width: 关卡宽度
  - name: 关卡名称
```

### 4.4 相机系统
- 相机跟随玩家移动
- 限制相机活动范围
- 关卡边缘停止滚动
